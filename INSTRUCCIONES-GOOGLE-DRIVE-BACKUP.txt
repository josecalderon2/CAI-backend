================================================================================
  INSTRUCCIONES PARA CONFIGURAR GOOGLE DRIVE BACKUP CON NUEVA CUENTA
================================================================================

IMPORTANTE: Este proceso solo se hace UNA VEZ cuando cambies de cuenta de Google.

================================================================================
PASO 1: CREAR PROYECTO EN GOOGLE CLOUD CONSOLE
================================================================================

1. Ve a: https://console.cloud.google.com/
2. Inicia sesión con la cuenta de Google DEFINITIVA que usarás
3. Crea un nuevo proyecto o usa el existente "cai-backups-477915"
4. Habilita la API de Google Drive:
   - Ve a "APIs y servicios" > "Biblioteca"
   - Busca "Google Drive API"
   - Haz clic en "Habilitar"

================================================================================
PASO 2: CREAR CARPETA EN GOOGLE DRIVE
================================================================================

1. Ve a: https://drive.google.com/
2. Crea una carpeta llamada "Backups CAI" (o el nombre que prefieras)
3. Abre la carpeta y copia el ID de la URL:
   - La URL será algo como: https://drive.google.com/drive/folders/XXXXXXXXXXXXXXXXXX
   - Copia solo la parte "XXXXXXXXXXXXXXXXXX" (el ID de la carpeta)
   - Guárdalo para usarlo después en el .env

================================================================================
PASO 3: CONFIGURAR OAUTH CONSENT SCREEN
================================================================================

1. Ve a: https://console.cloud.google.com/apis/credentials/consent
2. Selecciona "External" (Externo)
3. Completa el formulario:
   - Nombre de la aplicación: "CAI Backups"
   - Correo de asistencia: tu correo definitivo
   - Logo: (opcional)
   - Dominio de la aplicación: (opcional)
   - Correo de contacto del desarrollador: tu correo definitivo
4. Haz clic en "Guardar y continuar"

5. En "Ámbitos" (Scopes):
   - Haz clic en "Agregar o quitar ámbitos"
   - Busca y selecciona: ".../auth/drive.file"
   - Haz clic en "Actualizar" y luego "Guardar y continuar"

6. En "Usuarios de prueba":
   - Haz clic en "Agregar usuarios"
   - Agrega el CORREO DEFINITIVO que usarás
   - Haz clic en "Guardar y continuar"

7. Haz clic en "Volver al panel"

================================================================================
PASO 4: CREAR CREDENCIALES OAUTH 2.0 (TIPO DESKTOP APP)
================================================================================

⚠️ IMPORTANTE: Debe ser tipo "Desktop app", NO "Web application"

1. Ve a: https://console.cloud.google.com/apis/credentials
2. Haz clic en "+ Crear credenciales" > "ID de cliente de OAuth"
3. Tipo de aplicación: Selecciona "Aplicación de escritorio" (Desktop app)
4. Nombre: "CAI Backup Desktop"
5. Haz clic en "Crear"
6. Descarga el archivo JSON haciendo clic en el botón de descarga
7. El archivo se llamará algo como: "client_secret_XXXXX.apps.googleusercontent.com.json"

================================================================================
PASO 5: CONFIGURAR EL PROYECTO NESTJS
================================================================================

1. Renombra el archivo descargado a: "oauth-credentials.json"

2. Copia el archivo a la raíz del proyecto:
   C:\Users\carli\Downloads\Colegio amigos de israel\Backend\cai-back-end\oauth-credentials.json

3. Verifica que el contenido del archivo tenga esta estructura:
   {
     "installed": {
       "client_id": "...",
       "project_id": "cai-backups-477915",
       "auth_uri": "https://accounts.google.com/o/oauth2/auth",
       "token_uri": "https://oauth2.googleapis.com/token",
       "client_secret": "...",
       "redirect_uris": ["http://localhost"]
     }
   }

   ⚠️ IMPORTANTE: Debe decir "installed" NO "web"

4. Actualiza el archivo .env con estos valores:
   
   GOOGLE_OAUTH_CREDENTIALS_PATH="./oauth-credentials.json"
   GOOGLE_TOKEN_PATH="./google-token.json"
   GOOGLE_DRIVE_FOLDER_ID="ID_DE_TU_CARPETA_DE_DRIVE"

   (Reemplaza "ID_DE_TU_CARPETA_DE_DRIVE" con el ID que copiaste en el PASO 2)

5. Si existe el archivo "google-token.json", BÓRRALO:
   C:\Users\carli\Downloads\Colegio amigos de israel\Backend\cai-back-end\google-token.json

================================================================================
PASO 6: AUTORIZAR LA APLICACIÓN (SOLO UNA VEZ)
================================================================================

1. Reinicia el servidor NestJS:
   - Detén el servidor (Ctrl+C)
   - Ejecuta: npm run start:dev

2. Haz login como admin:
   POST http://localhost:3000/auth/login
   {
     "correo": "admin@colegio.edu",
     "contrasenia": "Admin123*"
   }
   
   Copia el token que te devuelve.

3. Obtén la URL de autorización:
   GET http://localhost:3000/backup/autorizar-google
   Authorization: Bearer TU_TOKEN_AQUI

4. Copia la URL que te devuelve y ábrela en el navegador

5. Selecciona la cuenta de Google DEFINITIVA

6. Autoriza la aplicación (acepta los permisos)

7. Google te redirigirá a una página con una URL como:
   http://localhost?code=4/0Ab32j93CwtFqHK...&scope=...

8. Copia SOLO el código que aparece después de "code=" y antes de "&scope"
   Por ejemplo: 4/0Ab32j93CwtFqHKrrWHYJrJ2pYW92NO7W6E9JWytigYKCjNMxeVv168dfq-d7uK2_Z6OasQ

9. Guarda el token ejecutando:
   POST http://localhost:3000/backup/guardar-token?code=TU_CODIGO_AQUI
   Authorization: Bearer TU_TOKEN_AQUI

10. Si recibes el mensaje "Token guardado exitosamente", ¡todo está listo!

================================================================================
PASO 7: PROBAR EL BACKUP
================================================================================

1. Ejecuta un backup manual:
   POST http://localhost:3000/backup/ejecutar
   Authorization: Bearer TU_TOKEN_AQUI

2. Verifica que:
   - El servidor crea el archivo SQL
   - Sube el archivo a Google Drive
   - Te devuelve un link para ver el archivo
   - El archivo aparece en tu carpeta de Google Drive

3. Si todo funciona correctamente, ¡el sistema está configurado!

NOTAS IMPORTANTES
================================================================================

 El proceso de autorización (PASO 6) SOLO SE HACE UNA VEZ por cuenta

================================================================================
PROBLEMAS COMUNES Y SOLUCIONES
================================================================================

 Error "Service Accounts do not have storage quota"
    Solución: Usar OAuth 2.0, NO Service Account

 Error "Cannot GET /backup/oauth-callback"
    Solución: Usar tipo "Desktop app", NO "Web application"

 Error "redirect_uri_mismatch"
    Solución: Verificar que el tipo sea "Desktop app" (no requiere redirect URI específico)

 Error "Token de Google Drive no encontrado"
    Solución: Completar el PASO 6 de autorización

 Error de autenticación de PostgreSQL
    Solución: Ya está resuelto con la creación temporal de archivo .pgpass

 El backup no sube a Drive
    Solución: Verificar que el GOOGLE_DRIVE_FOLDER_ID sea correcto y que la cuenta tenga acceso
